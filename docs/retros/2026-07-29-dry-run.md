## What the work was

Bootstrap from the template (ids discovered, ruleset enforced), a five-rung
ladder with a verified-disjoint parallel group, rung 1 built and merged
through: plan comment, build, async diff verify (fix-first, 3 real findings),
forced ADR 0002 via the proposed-implemented path (CI red → ruling → green),
timeout abort, full-mode verify (machinery proven, environment limits
captured), documented deliberate merge. Artifacts: PRs #9 #10, issues #1–#12,
ADRs 0001–0003, 2 fixtures.

## What went wrong

1. `.gitignore` had no stack ignores — node_modules committed once (PR #10).
2. adr.sh title regex broke on CRLF-edited templates (kit fix shipped).
3. The init chain silently skipped docs/architecture.md after an earlier
   command in the chain failed (accept died later; restored by hand).
4. verify.sh could not re-verify a verdict-bearing PR (kit fix shipped).
5. Full-mode exec limits: EPERM in sandbox; stale system node (ADR 0004).
6. A kit-sync rider rode a rung PR outside its declared surface — flagged by
   the verify, correctly.

## Root causes

A. Init steps chained with && silently skip later steps on failure — the
   installer needs per-step verification, not one long chain.
B. The kit was authored on Windows but its templates assumed LF.
C. Full-mode assumed sandbox exec parity with the shell; unproven until run.

## What worked well — do not break these

Async claim/verdict/abort held under every failure; codex's verdicts were
genuinely adversarial (surface violations, unpinned invariants, missing
ADRs); the forced-decision path ran on a real finding; watch.sh woke on real
transitions; every abort released its claim; no fake verdict was ever
synthesized.
